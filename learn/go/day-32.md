# Day 32: First REST API Project (MVP) — CRUD Endpoints

## 1. Implement Create

POST /tasks creates new records.

## 2. Implement Read

GET /tasks and GET /tasks/{id} with 404 handling.

## 3. Implement Update

PATCH /tasks/{id} updates existing records.

## 4. Implement Delete

DELETE /tasks/{id} returns 204.
